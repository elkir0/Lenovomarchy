`pkgs.omamobile.org/stable/aarch64` and from
`github.com/derekross/omarchy-mobile` at c462357 (2026-11-16).

The recipes under `image/pkg/` said the upstream repository was gone. It
moved: `github.com/omarchy-mobile/omarchy-mobile` is a 404,
`github.com/derekross/omarchy-mobile` is live and publishes a signed
package repository.

Upstream states there is no way back from 4.5 to 4.0.6 short of
reinstalling, and that 4.5's migrations can install packages that replace
the mobile ones unless they are held (its `omamobile-update` does that).
